# Gungnir

Minecraft 1.20.2 / Fabric Loader 0.15.8 / Java 17 mod.

Adds a trident named Gungnir. When thrown, it searches for hostile living entities within 5 blocks, steers toward the nearest target, applies Loyalty III behavior, and inflicts permanent bleeding for 0.5 damage per second.
